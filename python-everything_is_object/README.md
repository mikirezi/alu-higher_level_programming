# python-everything_is_object

This project explores Python's object model — every value in Python, from integers to functions, is an object with an identity (`id`) and a type (`type`).

Topics covered:

- Object identity vs equality (`is` vs `==`)
- Mutable vs immutable objects
- How variable assignment and referencing work
- How arguments are passed to functions
- Shallow copying of lists
- Tuples and their immutability nuances
